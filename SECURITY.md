# Security Policy

## Supported versions

Security fixes go into the latest release. Please update before reporting an issue.

## Reporting a vulnerability

**Please do not open a public issue.** Use GitHub's [private vulnerability reporting](https://github.com/AlanEdward19/waymark/security/advisories/new) or email **alan-edward@outlook.com.br** with:

- a description of the issue and its impact,
- steps to reproduce,
- the version and platform you tested.

You can expect an acknowledgement within 72 hours and an update on the fix within 14 days. We'll credit you in the release notes unless you prefer otherwise.

## Scope

Areas we are especially interested in, as the project grows: permission enforcement at query time, storage of API keys and tokens, bot/webhook authentication, ingestion of untrusted content, and the MCP/HTTP interfaces.
